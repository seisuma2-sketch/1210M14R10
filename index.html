よくある質問

インターネット接続は必要ですか

ダウンロード時以外は必要ありません。PC どうしは Bluetooth と Wi-Fi Direct で直接つながり、クラウドやルーターを経由しません。

相手の PC にもインストールが必要ですか

はい。送る側と受け取る側の両方に 1210M14R10 をインストールし、Bluetooth を有効にしてください。受け取る側の PC ではカメラは起動しません。

Web カメラがなくても使えますか

ジェスチャー操作にはカメラが必要ですが、ファイルをウィンドウへドラッグ & ドロップして送ることもできます。

Wi-Fi Direct に対応していない PC では

Bluetooth のまま転送を続けます。大きなファイルは時間がかかりますが、写真やクリップボードの同期は問題なく行えます。

カメラの映像は保存・送信されますか

いいえ。映像はこの PC の中で手の関節位置を求めるためだけに使われ、保存も外部への送信もされません。

Python を別に入れる必要はありますか

ありません。ビジョンエンジン用の Python ランタイムと必要なライブラリはインストーラーに同梱されています。

ファイアウォールの確認が表示されました

PC どうしの転送に通信ポートを使うため、初回に Windows のファイアウォールの許可を求められることがあります。プライベート ネットワークで許可してください。

アンインストールするには

Windows の「設定」から「アプリ」、「インストールされているアプリ」を開き、1210M14R10 の「アンインストール」を選んでください。
