隣の PC

必要な時だけ高速に

大きなファイルを送る瞬間だけ Wi-Fi Direct に切り替え、終わって 20 秒たつと自動で解除して Wi-Fi を休ませます。相手と名前が完全に一致した機器にしか接続しません。

途切れない

Wi-Fi Direct が使えない時も、写真や小さなファイルは Bluetooth のまま届けます。何時間もかかる大きなファイルは無理に送らず、すぐに知らせてバッテリーを守ります。

何でも送れる

写真、ファイル、フォルダ丸ごと。エクスプローラーの右クリック「送る」からも送れます。コピーした文字や画像は、ボタンかショートカットを押した時だけ相手へ届けます。

よくある質問

インターネット接続は必要ですか

ダウンロード時以外は必要ありません。PC どうしは Bluetooth と Wi-Fi Direct で直接つながり、クラウドやルーターを経由しません。

相手の PC にもインストールが必要ですか

はい。送る側と受け取る側の両方に 1210M14R10 をインストールし、Bluetooth を有効にしてください。受け取る側の PC ではカメラは起動しません。

Web カメラがなくても使えますか

ジェスチャー操作にはカメラが必要ですが、ファイルをウィンドウへドラッグ & ドロップして送ることもできます。

Wi-Fi Direct に対応していない PC では

1 MB 未満の写真や小さなファイル、クリップボードは Bluetooth で送れます。1 MB 以上のファイルは Bluetooth では何時間もかかるため送らずに中止し、画面でお知らせします。Wi-Fi が OFF になっているだけなら、アプリが自動で ON にしてから接続します。

クリップボードの共有はできますか

できます。接続中に「クリップボードを送信」ボタンか Ctrl + Alt + Shift + C を押すと、その時にコピーしていた文字や画像が相手の PC のクリップボードへ届きます。コピーのたびに自動で送ることはありません。

受け取ったファイルはどこに保存されますか

最初は 1210M14R10 のデータフォルダ内の received_files です。設定画面 (全画面表示の [ 設定 ]) から、ダウンロード フォルダや好きなフォルダに変更できます。受け取った時に出るカードの [ フォルダ ] からも開けます。

カメラの映像は保存・送信されますか

いいえ。映像はこの PC の中で手の関節位置を求めるためだけに使われ、保存も外部への送信もされません。

Python を別に入れる必要はありますか

ありません。ビジョンエンジン用の Python ランタイムと必要なライブラリはインストーラーに同梱されています。

ファイアウォールの確認が表示されました

PC どうしの転送に通信ポートを使うため、初回に Windows のファイアウォールの許可を求められることがあります。Wi-Fi Direct の接続は Windows ではパブリック ネットワークとして扱われるため、受け取る側の PC では「パブリック」でも許可してください。許可していないと、大きなファイルを Wi-Fi Direct で受け取れません (1.1.1 からは、ブロックされている時にアプリが画面で知らせます)。後から変える場合は、Windows セキュリティの「ファイアウォールによるアプリケーションの許可」で 1210M14R10 の「パブリック」にチェックを入れます。

アンインストールするには

Windows の「設定」から「アプリ」、「インストールされているアプリ」を開き、1210M14R10 の「アンインストール」を選んでください。
